# Aesthetic Derivation: The Uniqueness Engine

How to derive a distinctive visual direction from product context instead
of converging on the default. Read when creating any new design from
scratch or diagnosing why a design feels generic.

## 1. The Derivation Method

Never select an aesthetic from a menu -- menus are how defaults reproduce.
Derive it:

1. Rank the three brand adjectives. #1 wins every tie.
2. List 5 artifacts from the product's PHYSICAL world (tools, packaging,
   documents, environments its users touch).
3. For each artifact, extract one transferable visual property (a texture,
   a typographic tradition, a color relationship, a structural motif).
4. Pick the 1-2 properties that serve the #1 adjective. That's your
   direction seed. Type, color, and layout choices now answer to it.

Worked example -- specialty coffee subscription, adjectives "artisanal >
honest > warm": artifacts are kraft bags (unbleached fiber texture,
stamped type), roast-curve charts (a beautiful data motif nobody uses),
cupping cards (structured scoring tables), burlap stencils (condensed
grotesque caps), hand-written batch tags. Seeds: stamped/stencil type
tradition + roast-curve as graphic motif. Nothing in that list produces
a centered hero with a serif and a gradient.

## 2. Typography Voices

Typeface choice is the loudest single design decision. Choose by voice,
and range widely -- these are examples per voice, not a canon:

- **Grotesque/neo-grotesque** (workhorse confidence): Helvetica Now,
  Suisse Int'l, Neue Haas, Aktiv, Archivo
- **Geometric sans** (engineered optimism): Futura PT, Sohne, Poppins,
  DM Sans, General Sans
- **Humanist sans** (approachable clarity): Frutiger, Source Sans, Work
  Sans, Mulish
- **Condensed/display grotesque** (attitude, urgency, sport): Druk,
  Archivo Expanded/Condensed, Barlow Condensed, Anton
- **Editorial serif** (authority, culture): Freight, Tiempos, Source
  Serif, Newsreader
- **High-contrast display serif** (luxury, fashion): Canela, Ogg,
  Playfair, Fraunces
- **Slab** (sturdy, honest, mechanical): Roboto Slab, Zilla, Arvo
- **Mono/semi-mono** (technical truth, receipts, data): JetBrains Mono,
  Space Grotesk, IBM Plex Mono, Fragment Mono
- **Quirky/character display** (indie, human, playful): Fraunces (soft),
  Gambetta, Clash Display, Bricolage Grotesque

Rules of engagement: the display face carries the personality, the text
face carries the reading; they should contrast in voice, not compete.
Defaulting to Inter (or one serif you always reach for) without a
derivation is a banned reflex. Variable-font width/weight extremes are an
underused personality dial.

## 3. Layout Structures Beyond the Centered Stack

Pick the structure that serves the screen's emotional job:

- **Split-stage (7/5 or 8/4):** content one side, evidence (image, demo,
  data) the other. The workhorse alternative to centering.
- **Editorial column:** a strong left-aligned text column with generous
  right whitespace; reads as confident and literate.
- **Poster:** one enormous typographic statement, tiny supporting cast.
  Maximum drama, works when the message is short.
- **Bento:** unequal-sized tiles, each a distinct proof point. For products
  with many small demonstrable features -- earns its popularity ONLY when
  tile sizes reflect real importance.
- **Ledger/index:** dense ruled rows like a table of contents. Radically
  distinctive for content-heavy or archival products.
- **Overlap/collage:** elements layered with deliberate misregistration.
  For culture/fashion/creative products.
- **Diagonal/rotated axis:** a single angled element breaks the horizontal
  monotony. Use once, anchor everything else.
- **Full-bleed immersive:** photography or motion IS the layout, UI floats
  minimally. For products selling atmosphere (travel, hospitality, food).

The centered stack is legitimate for moments of ceremony (a confirmation,
a single-action page). As a homepage default it is the uniform of sameness.

## 4. Color Logic Beyond "Brand Color + Gray"

- **Tonal field:** one hue family at many lightness steps (paper to ink of
  the same temperature). Quietly distinctive; luxury and editorial love it.
- **Ink + paper + one shout:** near-mono base with a single loud accent
  used at <5% coverage. The accent becomes the signature.
- **Complementary tension:** two opposed hues, one dominant, one for
  punctuation only.
- **Material palette:** sample colors from the product's physical world
  (roast browns + parchment + copper; sea glass + sand + rope) rather than
  from other UIs. Instantly non-generic because it's sourced from reality.
- **Functional color:** hues carry data meaning only (finance, dashboards);
  the brand lives in type and structure instead.

Whatever the logic: 60-30-10 distribution, max 3 hues + neutrals, one gray
temperature, AA contrast. The logic picks the colors; the system disciplines
them.

## 5. Material Transfer by Industry

Steal from the product's world, not from Dribbble:

| Product world | Physical artifacts | Transferable properties |
|---|---|---|
| Coffee / food craft | Kraft bags, stamps, cupping cards, menus | Stamped type, batch-tag labels, scoring tables, paper tones |
| Finance | Ledgers, receipts, security print, terminals | Ruled rows, tabular numerals, guilloche-fine patterns, mono data |
| Fitness / sport | Jerseys, track paint, stopwatches, plates | Big numerals, lane lines, condensed caps, high-contrast timing displays |
| Travel / hospitality | Boarding passes, luggage tags, old timetables | Ticket structures, perforation motifs, destination boards |
| Music / culture | Gig posters, liner notes, cassette labels | Poster type scale, overlap, tracklist indexes |
| Health / care | Charts, prescriptions, appointment cards | Calm tonal fields, form clarity, generous line-height |
| Developer tools | Terminals, logs, blueprints, schematics | Mono type, syntax color logic, grid-paper backgrounds |
| Kids / education | Workbooks, stickers, flashcards | Chunky shapes, primary-plus palettes, handwriting accents |
| Legal / gov | Documents, seals, index tabs | Numbered clauses, tab navigation as physical tabs, formal serifs |

The transfer is a property, never a costume: a fintech app borrows the
LEDGER'S ruled discipline, it doesn't cosplay as an 1890s bank.

## 6. Signature Elements: A Starter Vocabulary

One per design. Examples of ownable moves:

- An oversized numeral system (step numbers, prices, stats at 6-10x body)
- A distinctive rule language (double rules, dotted separators, one thick
  anchor rule per view)
- A custom underline/highlight style on links or key phrases
- One recurring geometric motif derived from the logo or product
- A characteristic image treatment (duotone in brand hues, hard-edged
  cutouts, consistent grain)
- A grid-break that repeats predictably (every section's image bleeds left)
- An unexpected-but-derived color pairing used only for interactive moments
- A distinctive corner treatment (one notched corner, asymmetric radii)

The signature must survive the derivation test: it comes FROM the product's
world, it isn't glued on.

## 7. Anti-Convergence Tactics

When you catch yourself producing the same design again:

- **Invert one axis:** if it's light, try dark; centered, try hard-left;
  airy, try dense. Keep the inversion only if it serves the #1 adjective.
- **Swap the hierarchy carrier:** if size carries hierarchy, try weight or
  color or position carrying it instead.
- **Design the most distinctive screen first** (a receipt, a stats page, a
  ticket) and let its DNA flow backward into the generic screens, instead
  of designing the homepage first and stamping it everywhere.
- **Steal from print:** magazines, tickets, packaging, and record sleeves
  solved layout before the web existed and don't share the web's defaults.
- **The tomorrow test:** name the one thing a user would remember tomorrow.
  If the honest answer is "nothing", the design isn't finished.

## 8. The Asset Library Map

Free, licensed sources for when the user has no assets. Always check the
current license of the specific asset -- some require attribution, terms
change. One library per asset type per product; mixing systems is how
visual consistency dies.

| Asset type | Libraries | Craft rule |
|---|---|---|
| Photography | Unsplash, Pexels, Pixabay | One treatment across all photos (duotone in brand hues, uniform crop) so mixed sources read as one voice |
| Illustration | unDraw (recolorable), Storyset, Open Peeps, Humaaans, DrawKit | Commit to ONE system per product, recolor to tokens; never mix styles |
| Icons | Lucide, Tabler, Phosphor, Heroicons, Iconoir | One family, one weight (see SKILL.md Step 5) |
| Patterns / backgrounds | Hero Patterns, Haikei exports | Derive colors from the palette; patterns are texture, not decoration |
| Avatars | DiceBear (seedable, many styles), Boring Avatars | Pick one style; seed by user ID for stability |
| Typography | Google Fonts, Fontshare (General Sans, Clash, Satoshi, etc.) | Load the REAL typeface in every mockup -- never approximate a direction's voice with a default font |

Delivery paths by environment:
- **In code:** npm/CDN for icons and fonts; direct URLs for stock
  photography; SVG downloads for illustration and patterns.
- **In Figma:** fetch the chosen asset and place it with the assets-upload
  tool as a frame fill; illustration SVGs import via createNodeFromSvg.
- **In chat mockups:** load real typefaces from font CDNs; where external
  images are blocked, show the chosen photograph alongside the mockup as
  an art-direction reference and build the mockup's image area as a
  treatment-true tonal composition.

License hygiene: state the source and license of every third-party asset
in the handoff. "Found it online" is not a license.

## 9. Background & Visual-Detail Techniques

Create atmosphere and depth rather than defaulting to solid colors:

- **Gradient meshes** -- large, soft, animated or static
- **Noise textures** -- barely visible grain at 2-5% opacity prevents the
  "flat CSS" feel
- **Geometric patterns** -- dot grids, diagonal lines, subtle SVG textures
- **Layered transparencies** -- stacked shapes with blend modes
- **Dramatic shadows** -- colored, oversized, with offset that belongs to
  the direction
- **Decorative borders** -- hatched, double-line, vintage
- **Custom cursors** -- for immersive products only
- **Grain overlays** -- film grain for warmth, digital noise for edge

## 10. Named Clichés to Avoid on Sight

The hallmarks of generic, default-driven interfaces -- recognize these on
sight and treat them as a stop sign, not a starting point:

- **Purple gradients on white backgrounds** -- the single strongest
  AI-generated tell
- **Mint on near-black** -- the crypto-SaaS default
- **Pastel rainbow with soft shadows** -- the Figma-preset look
- **Teal + near-black, or dark mode with purple accents** -- the "safe"
  dark-mode reflex
- **Overused font families:** Inter, Roboto, Arial, or system fonts as the
  default body + heading combo
- **Predictable layouts:** centered hero, three-column feature grid, final
  CTA section -- executed exactly this way every time
- **Cookie-cutter components:** the same shadcn card, the same gradient
  button, the same floating nav
- **Design that lacks context-specific character** -- it would look
  identical if the content were swapped for a different product

Catching one of these mid-design is the moment to stop and ask: what
aesthetic direction am I committed to? If there isn't a clear answer, go
back to section 1.

## 11. Checklist Before Shipping

- [ ] Can I name the aesthetic direction in one phrase? ("brutalist
  editorial", "retro-futuristic dashboard")
- [ ] Does every screen and component serve that direction?
- [ ] Could this be mistaken for a default AI-generated interface? (If
  yes: regress.)
- [ ] Is typography doing real work, or is it Inter because Inter?
- [ ] Does the color palette have a clear lead, or is it evenly-distributed
  mush?
- [ ] Is there at least one detail someone will remember after closing the
  tab?
- [ ] Does the motion language match the aesthetic direction, or is it
  default fades everywhere?
- [ ] Do the backgrounds create atmosphere, or are they solid white/black
  by default?

If any answer is weak, you haven't finished. Commit harder.
